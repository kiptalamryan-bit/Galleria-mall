# Deployment Guide: Manual GitHub Pages + GitHub Actions Connection

## Overview

This project is a **Vite-based static website** ("Galleria Mall") hosted on GitHub. There are **two deployment paths** that connect together:

1. **Manual Approach** (using `gh-pages` package) — deploys via command line
2. **GitHub Actions Workflow** (see `.github/workflows/deploy.yml`) — automated deployment via CI/CD

Both approaches deploy the same output: the `dist/` folder generated by `vite build`.

---

## Two Approaches Explained

### 1️⃣ Manual Deployment (using `gh-pages`)

**What it does:** Builds your project and pushes the `dist/` folder to the `gh-pages` branch of your GitHub repo, which GitHub Pages serves.

**Command:**
```bash
npm run deploy
```

**What this command does:**
```
npm run build    → Runs "vite build" → creates dist/ folder
npx gh-pages -d dist  → Pushes dist/ to gh-pages branch on GitHub
```

**Prerequisites:**
- Node.js installed locally
- `gh-pages` installed (already in `package.json` devDependencies)
- Git configured with your GitHub credentials

---

### 2️⃣ GitHub Actions (Automated, Automated Deployment)

**What it does:** When you push to `main` branch, GitHub Actions automatically:
1. Checks out your code
2. Sets up Node.js
3. Installs dependencies (`npm ci`)
4. Builds the project (`npm run build`)
5. Uploads `dist/` as an artifact
6. Deploys it to GitHub Pages

**Trigger:** Push to `main` branch OR manual trigger from Actions tab

**Configuration file:** `.github/workflows/deploy.yml` (already created)

---


## Connection Between Manual and GitHub Actions

| Aspect | Manual (gh-pages) | GitHub Actions |
|---|---|---|
| **Trigger** | You run `npm run deploy` | Push to `main` or manual trigger |
| **Build location** | Local machine | GitHub-hosted Ubuntu runner |
| **Output** | `dist/` pushed to `gh-pages` branch | `dist/` uploaded as artifact → deployed |
| **Speed** | Faster (local build) | Slightly slower (CI pipeline) |
| **Reliability** | Depends on local environment | Consistent environment (always Ubuntu + latest Node) |
| **Version control** | `gh-pages` branch is auto-managed | Workflow file is versioned in `.github/` |
| **Visibility** | Terminal output only | Full logs in GitHub Actions tab |

## Troubleshooting

### Issue: `gh-pages` not found
```powershell
npm install gh-pages --save-dev
# or
npm ci
```

### Issue: Build fails
```powershell
npm run build  # Run locally to see error
```

### Issue: Pages 404 after deployment
- Wait 5-10 minutes for GitHub Pages to propagate
- Check that the repository is public (or has proper settings)
- Verify the `gh-pages` branch exists

### Issue: Images/videos not loading
- Check that image paths in `index.html` are correct
- The `public/` folder is copied as-is to `dist/`
- Verify `vite.config.js` has `publicDir: 'public'`
